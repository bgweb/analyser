Student Voice — Survey Analyser

Upload scanned completed forms, review the detected answers, and collate the results.

1. Upload completed surveys

Choose a PDF containing one or more scans of the same one-page Student Voice form. Processing runs in this browser; the PDF is not uploaded to a server. For best results, use upright, full-page scans with the page edges visible.

Ready. First use needs an internet connection to load the PDF library.

2. Review and correct detections

Checkbox detection counts each clearly marked option independently, including multiple marks. Answer-selection boxes stay hidden unless you press “Edit answers” on a page. Review the totals and correct any detections that need it.

3. Collated results

Questions detected from your master form

14 rating statements, each with five response options. Only tick-box responses are analysed; written text is ignored.

Privacy note: this single-page prototype uses third-party open-source libraries loaded from CDNs. PDF pages and results stay in the browser session unless you download an export. Avoid using it on a shared device without clearing the page afterwards.
